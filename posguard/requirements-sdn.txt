# immutable in a way Ryu's eventlet hub doesn't handle. All three fixes
# were needed together, not individually.
#
# Before trusting this file on a fresh machine, confirm what's ACTUALLY
# installed and proven working in your current sdn_env, and update this
# file to match reality rather than assuming these numbers are still
# exactly right:
#   sdn_env/bin/pip freeze | grep -Ei "setuptools|eventlet|ryu"
#
# scripts/verify_sdn_env.py checks a running environment against this
# file automatically.
